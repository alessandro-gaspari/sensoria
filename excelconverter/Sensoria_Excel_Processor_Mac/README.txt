Sensoria Excel Processor (macOS)

Contenuto:
- Sensoria Excel Processor.app

Come usare:
1) (Opzionale) sposta "Sensoria Excel Processor.app" in Applicazioni.
2) Apri l'app.
3) Seleziona file input .xlsx e file output .xlsx.
4) Premi "Elabora File".

Se macOS blocca l'app al primo avvio:
- Impostazioni di Sistema -> Privacy e Sicurezza -> "Apri comunque"
Oppure:
- Tasto destro sull'app -> Apri

Compatibilita': macOS
